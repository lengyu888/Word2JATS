# Word2JATS 错误案例分析

本报告根据本地 golden 评测结果自动列出未满分指标，便于答辩时说明真实边界。

## 典型失败样例

- **eval_formula_05.docx**：未满分解析指标为 `formula_count`。
- **eval_anomaly_01.docx**：未满分解析指标为 `title, abstract`。
- **eval_anomaly_02.docx**：未满分解析指标为 `abstract`。
- **eval_anomaly_03.docx**：未满分解析指标为 `title, abstract`。
- **eval_anomaly_04.docx**：未满分解析指标为 `abstract`。
- **eval_anomaly_05.docx**：未满分解析指标为 `title, abstract, section_title`。

## 系统性出版元数据缺口

- 原始转换正式 Schema 通过率为 `0.0%`；合成 Word 原稿不内置 ISSN 等期刊级元数据，系统不会自动编造。
- 使用 golden 模拟人工补充出版元数据后，正式 Schema 通过率为 `100.0%`。

## 复杂公式稳定降级案例

- 唯一验收稿 `word2jats_final_acceptance.docx` 包含矩阵、分段函数、带上下限大运算符、常见重音和一个故意加入的复杂 OMML 子结构。
- 可支持公式输出 MathML/LaTeX 并标记 `success`；未知复杂结构保留可识别内容并标记 `partial`，不会导致整篇转换或 JATS 生成失败。

## 结构歧义与引用目标案例

- 图题、表题与对象只有在同章节、编号一致且文档流距离合理时才作为高置信绑定；缺题注、仅题注或证据不足的对象保留并标记 `need_review`，不跨章节强制配对。
- OMML 公式段、纯公式段、编号与对齐提供独立展示公式证据；正文内联数学不会自动提升为 `disp-formula`。
- 正文引用会先与实际 JATS ID 集合比对。缺失目标不生成无效 `rid`，原文仍保留，校验结果和质量报告同时给出缺失目标与人工复核建议。

## 后续优化方向

- 增加跨页表格、复杂合并单元格和嵌套列表样本。
- 继续扩展复杂嵌套矩阵、多重重音和未知 OMML 子结构。
- 为扫描图片公式增加离线 OCR 插件接口。
- 扩充不同期刊参考文献风格的字段级 golden 标注。
- 根据正式 JATS DTD 错误定位持续补齐期刊级必填元数据。
