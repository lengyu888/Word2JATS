## 结论

- 文档流解析主要提升章节、图片与表格绑定能力。
- OMML 转换直接改善原生公式结构化交付能力。
- xref 恢复补齐正文引用与目标对象之间的出版语义。
- Profile 与正式 Schema 校验形成面向期刊交付的质量闭环。
